# Ceramic Network

Attempts for studying ceramic production chaine operatorie and cultural interaction using probabilistic, network, and topic-model approaches.

## Main directories

- `ceramic-network-inference/` — current project and main analysis.
  - `notebooks/ceramic_network_inference.ipynb` contains the polished notebook and the main analysis with topic models.
  - `notebooks/new_attempts_experiments.ipynb` contains the new type of ideas (not checked profoundly)
  - `src/chaine/` contains reusable modelling and analysis code.
  - `scripts/` prepares the data.
  - `tests/` contains automated tests.
  - See its `README.md` for installation and detailed results.

- `Old_code/` — earlier exploratory implementations, notebooks, scripts, results, and plots. These are useful for historical context but are not the primary code path.

- `erikdata/` — standalone tools for generating, converting, comparing, and analysing ceramic production paths from Kroon's thesis.

For the current analysis, open:

ceramic_network_inference.ipynb
